## 1. 快速上手

### 1.1 启动

- **源码启动**：在项目根目录执行 `python -m src.thoncode.main`；
- **打包启动**：Windows 下直接双击 `ThonCode.exe`。

首次启动会看到**欢迎页**，可以：

- 「新建文件」创建空白文档；
- 「打开文件…」打开已有源文件；
- 「打开文件夹」选择项目目录（推荐）；
- 「最近打开」从历史项目中恢复；
- 右下角取消「每次启动显示欢迎页」复选框可跳过。

### 1.2 主界面概览

```
┌────────────────────────────────────────────────────────────┐
│ 菜单栏：文件  编辑  项目  运行  工具  帮助                       │
├──────────────┬─────────────────────────────────────────────┤
│              │ 标签栏  [main.py ●]  [utils.py]  +           │
│              ├─────────────────────────────────────────────┤
│  文件树       │                                             │
│              │               代码编辑器                      │
│              │                                             │
│              │                                             │
├──────────────┴─────────────────────────────────────────────┤
│  状态栏：就绪 | 已打开项目: D:\code\my-app                     │
└────────────────────────────────────────────────────────────┘
```

## 2. 编辑器与快捷键

### 2.1 常用快捷键

| 快捷键 | 功能 | 对应欢迎页入口 |
| --- | --- | --- |
| `Ctrl+N` | 新建文件 | 新建文件 |
| `Ctrl+O` | 打开文件 | 打开文件 |
| `Ctrl+S` | 保存文件 | 保存文件 |
| `Ctrl+Shift+S` | 另存为 | 另存为 |
| `Ctrl+Shift+G` | 打开 Git 集成窗口 | Git 集成 |
| `F5`（可由插件扩展） | 运行当前文件 | 运行 |
| `Ctrl+Q` | 退出 | 退出 |

> 插件可通过 `PERMISSION_HOTKEY_BIND` 绑定更多快捷键，详见 [插件开发指南](./plugin_development.md) 第 7 章。

### 2.2 编辑体验

- Tab 缩进宽度：在「设置 → Tab 缩进空格数」中调整（默认 4）；
- 字体连字：启用「设置 → 启用连字」需系统已安装 Fira Code，IDE 自带的字体文件位于 `assets/fonts/FiraCode-Regular.ttf`，可手动安装；
- 语法高亮：内置 Python / Markdown / JavaScript / HTML / 纯文本；插件可通过 `PERMISSION_HIGHLIGHT_EXTEND` 扩展 Rust、Go 等语言。

### 2.3 多标签

- 打开多个文件会在编辑器顶部形成标签页；
- 在文件树双击新文件会**替换**当前标签（同 VSCode），插件可改变此行为；
- 已修改文件标签右侧有 `●` 标识。

## 3. 项目与文件树

### 3.1 打开项目

菜单栏「文件 → 打开文件夹」→ 选择项目根目录 → 左侧文件树加载。

> 未打开项目时，Git 集成、运行配置、最近项目等功能会受限，IDE 会在状态栏提示「未选择文件夹」。

### 3.2 文件树右键菜单

| 菜单项 | 作用 |
| --- | --- |
| 刷新 | 重新从磁盘扫描（快捷键：文件树顶部按钮） |
| 新建文件 | 在选中目录下创建文件，需输入含扩展名的完整名 |
| 新建文件夹 | 在选中目录下创建子目录 |
| 重命名 | 修改文件或文件夹名 |
| 移至回收站 | 安全删除（需系统已装 `send2trash`，否则会提示永久删除） |
| 删除 | **不可恢复**地永久删除，操作前会确认 |

### 3.3 目录结构查看器

菜单栏「项目 → 目录结构查看器」：

- 设定路径、最大深度后点击「刷新」；
- 支持「树形」文本导出与「JSON」结构化导出；
- 常用于生成项目结构文档、发 issue 时附带目录快照。

## 4. 插件管理与在线安装

### 4.1 打开插件管理

菜单栏「工具 → 插件管理」，窗口包含两个标签：

- **已安装**：列出本地 `plugins/` 目录下的插件（名称 / 版本 / 作者 / 描述 / 状态）；
- **插件市场**：从自定义市场 URL 拉取可在线安装的插件。

### 4.2 已安装标签

按钮：

| 按钮 | 作用 |
| --- | --- |
| 刷新 | 重新扫描 `plugins/` 目录并按权限 + 依赖加载 |
| 卸载 | 调用插件 `on_unload()`，清理菜单 / 快捷键 / 语法扩展，但**不删除磁盘文件** |
| 热重载 | 先卸载，再重新 `import` 最新源码，无需重启 IDE |

> 状态栏显示「已加载」或具体跳过原因（依赖缺失 / 宿主版本不兼容 / 权限被拒）。

### 4.3 插件市场标签

首次使用需要先在「设置」里填「插件市场 URL」（或在该标签直接输入后点「保存地址」）。

流程：

1. 点「刷新列表」→ 从 `{URL}/index.json` 拉取插件目录；
2. 在列表中选中需要的插件；
3. 点「安装 / 更新」→ 下载 zip →（可选）校验 SHA-256 → 解压到 `plugins/`；
4. 切回「已安装」标签 → 点「刷新」加载新插件。

> 自建市场步骤详见 [插件市场搭建指南](./plugin_marketplace.md)。

### 4.4 权限授权

首次加载一个声明了高风险权限（如网络、执行子进程、写任意文件）的插件时，会弹出「插件权限授权」对话框：

- 顶部列出该插件申请的所有权限；
- 用户可逐条勾选或全选 / 全不选；
- 点「允许」后，插件本次生命周期内只拿到**被勾选**的权限子集；
- 未勾选的权限对应 API 调用会被静默拒绝并记日志（不报错弹窗，避免干扰主流程）。

若日后想调整权限：卸载 → 再次加载会重新弹窗。

## 5. Git 集成与许可证管理

### 5.1 打开 Git 集成

菜单栏「项目 → Git 集成」（快捷键 `Ctrl+Shift+G`）。

窗口分为三块：

1. **项目选择区**：切换要操作的项目目录；若不是 Git 仓库，会提示并提供「初始化」按钮；
2. **分支区**：新建 / 切换 / 删除分支；
3. **操作区**：
   - 初始化 / 全部暂存 / 提交 / 推送 / 拉取 / 查看状态；
   - 更新日志管理；
   - **许可证管理**（详见 5.2）；
4. **文件状态区**：查看变更文件，单文件暂存 / 丢弃更改；
5. **输出面板**：命令行输出实时显示，便于排错。

> Git 未安装时会在顶部提示「Git 未安装」，所有按钮置灰。

### 5.2 许可证管理器

Git 集成窗口 → 「许可证 → 管理许可证」。

**窗口修复说明（v0.4+）**：旧版本中该窗口因层级问题必须先关闭 Git 窗口才能操作。现版本已通过以下方案解决：

- 使用 `ScrollableFrame` 作为内容容器，小屏幕 / 16:9 低分辨率下不会出现「预览区 150 行把窗口撑出屏幕、关闭按钮不可见」的问题；
- 预览文本框高度从硬编码改为 10 行，用户仍可上下滚动；
- 打开时自动释放 Git 集成窗口的 `grab`，关闭时还原，确保两个窗口**不会互相卡死**；
- 许可证模板目录使用「frozen / _MEIPASS / 源码」三级绝对路径解析，打包后也不会出现下拉为空。

使用步骤：

1. 从「选择许可证」下拉挑选内置模板（MIT / Apache-2.0 / GPL-3.0 … 首次运行会自动 materialize 一套）；
2. （可选）点「浏览文件」自定义许可证文本；
3. 填写「年份」「作者」等替换变量；
4. 实时查看「预览」区；
5. 「应用许可证」→ 在项目根生成 `LICENSE`；
6. 「移除许可证」→ 删除项目根的 `LICENSE`（有二次确认）。

### 5.3 更新日志管理

Git 集成窗口 → 「更新日志」，提供 Keep a Changelog 风格的可视化编辑：

- 支持分区（Added / Changed / Fixed / Deprecated / Removed / Security…，可自定义）；
- 分区下逐条增加条目；
- 一键导出 / 导入 `CHANGELOG.md`，或直接保存覆盖项目根下的 `CHANGELOG.md`。

## 6. 运行与调试

### 6.1 配置运行时

菜单栏「运行 → 配置运行时…」：

- Python 解释器路径：指定具体 `python.exe` / `python3`；
- 运行参数：以空格分隔，会拼接到命令末尾。

### 6.2 运行当前文件

菜单栏「运行 → 运行当前文件」（默认 F5，需在快捷键扩展里启用）：

1. 若文件有未保存修改，会弹窗询问是否先保存；
2. 按「运行时配置」选定的解释器执行 `python <当前文件> <参数>`；
3. stdout / stderr 导向「运行输出」面板（如集成在主界面底部，可由插件扩展此行为）。

### 6.3 项目配置

菜单栏「项目 → 项目配置」：

- 可以为**单个项目**独立设置 Python 解释器；
- 读取根目录的 `requirements.txt` 列出依赖库供查看。

## 7. 设置：语言、主题、插件市场

菜单栏「文件 → 设置」。

### 7.1 界面语言

目前提供：

| 选项 | 对应资源文件 |
| --- | --- |
| 简体中文 | `assets/langs/zh_cn.json` |
| English (US) | `assets/langs/en_us.json` |
| English (UK) | `assets/langs/en_uk.json` |

切换后会重新加载 i18n，所有窗口在下一次打开时使用新语言。若发现有未翻译项（显示为英文 key），欢迎发 PR 补充对应条目。

### 7.2 主题

- **内置主题**：由 ttkbootstrap 提供，下拉选择后**实时生效**——包括 VSCode 深蓝风格、浅色办公风格等；
- **主题色**（莫奈取色）：可从预设色板选，或「自定义…」取任意颜色；
- **自动重载配置**：启用后，保存设置无需重启立即生效（推荐开启）。

### 7.3 插件市场 URL

- 根 URL，不需要加 `/index.json` 后缀；
- 例如：`https://my-org.example.com/thoncode-market`；
- 留空则禁用插件市场的在线安装功能，插件管理窗口的「插件市场」标签会提示未配置。

### 7.4 编辑器高级

- **Tab 缩进空格数**：2 / 4 / 8（会实时影响当前所有编辑器）；
- **启用字体连字**：启用 Fira Code 的 `->`、`>=`、`===` 等连写字形。

## 8. 常见问题（FAQ）

### Q1：启动时报「Git 未安装」怎么办？

A：Git 集成模块要求系统已装 Git 并位于 `PATH`。去 <https://git-scm.com/downloads> 下载安装，安装时勾选「Add Git to PATH」，重启 Thon Code 即可。

### Q2：许可证管理下拉是空的？

A：两种可能：

1. 首次运行权限不够，IDE 无法在 `assets/license/` 写入内置模板 → 手动把 `src/thoncode/assets/license/` 目录放进去；
2. PyInstaller/Nuitka 打包时忘了把 `assets/license` 作为数据文件收进去 → 请参考「插件开发指南」第 12.2 节调整打包脚本。

### Q3：从 Git 集成窗口打开许可证管理后，两个窗口都点不动？

A：该问题在 v0.4.0 已修复。如果仍出现，请检查你的启动方式，确保使用的是新构建的二进制。临时绕过：**不要手动关闭 Git 窗口**，先关闭许可证窗口即可恢复；请附带构建版本到 issue 区反馈。

### Q4：热重载插件后，菜单重复出现？

A：请确保插件本身没有覆盖 `PluginBase` 的 `on_unload` 并手动注册菜单。所有通过 `self.api.add_menu_item(...)` 注册的菜单在卸载时由 `PluginAPI._unregister_all_for_plugin` 自动清理，插件不应自己实现额外的菜单清理逻辑。如果你确实在 `on_unload` 中手写了清理代码，移除后重试。

### Q5：插件市场安装时提示「Operation failed: Marketplace URL is not configured.」？

A：先在「设置 → 插件市场 URL」填入地址并点「保存」。如果已填写仍报错，检查地址末尾是否多加了空格或换行。

### Q6：16:9 屏幕上部分窗口底部按钮看不到？

A：v0.4.0 起所有窗口都接入了 `libs.gui.window_helper.ScrollableFrame`，请升级到最新版本；仍有问题的窗口（第三方插件自绘）请向插件作者反馈，要求其改用 `ScrollableFrame` 并设置合理的最小窗口尺寸。

### Q7：升级 Thon Code 后，配置 / 最近项目 / 授权记录会不会丢？

A：不会。这些都写在用户级配置文件里（通常位于 `%APPDATA%\ThonCode\` 或项目下的 `.thoncode\`，依 cfg_handle 策略而定）。升级只是替换二进制与内置资源，不动用户数据。

### Q8：如何完全重置 Thon Code？

A：关闭 IDE → 删除用户配置目录（启动时在日志第一行可看到具体路径，或运行 `test/quick_import_sanity.py` 打印）；删除后下次启动恢复出厂设置。
